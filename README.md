# Odin Recipes

A small recipe website in plain HTML: an index page that links to three recipes (lasagna, pizza, spaghetti).

**[View it live →](https://denizsev.github.io/odin-recipes/)**

## What I learned

- Structuring HTML pages with headings, lists and images
- Linking between pages with relative paths
- Using Git and GitHub for the first time

Built as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-recipes).
